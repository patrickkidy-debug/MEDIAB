Configuration Umami (une seule fois) :
  1. Crée un compte gratuit sur cloud.umami.is
  2. Ajoute un site : Settings → Websites → Add website (domaine : patrickkidy-debug.github.io)
  3. Copie le Website ID et colle-le dans js/analytics.js (ligne UMAMI_WEBSITE_ID)
  4. Pour afficher le dashboard ici : Edit → Enable share URL, copie l'adresse et colle-la ci-dessous dans admin.html (ligne UMAMI_SHARE_URL)
